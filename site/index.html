MangkorN/jigs

A jig is a guide a woodworker builds once so the same cut comes out exact every time. These are the software kind: each one does a single repetitive job and gets the fiddly details right, so you don't have to think about them again.

gitro

Read-only git for callers that shouldn't touch your repository, such as an AI agent working in a sandbox. The caller drops a request file into a folder, and gitro answers with the output of an allow-listed, read-only git command. The caller never gets the repository itself.

Run gitro

The other tools

Each one is documented in the README for now.

csbundle
Bundles a source tree's C# files into one text file per folder, ready to hand to a chat.
csapply
Puts edited files back into a project by matching file names, leaving Unity's .meta files alone.
gdm
Shows a git diff as only the lines that changed.
lsf, catcs
List every file under a folder, or print its C# files, optionally straight to the clipboard.
toclip
Copies any command's output to the clipboard.
vs-tabs
Saves and restores Visual Studio tab layouts by name.
