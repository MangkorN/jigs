Small, purpose-built tools for repetitive dev tasks.

Shell
bash (Git Bash on Windows)
Also

Source
MangkorN/jigs

A jig is a woodworking guide for making the same cut accurately every time. Each tool here does one repetitive dev job and handles the details that make it error-prone, such as Unity .meta files, byte order marks, line endings and clipboard encoding.

gitro

Read-only git access for programs that shouldn't touch your repository, such as an AI agent in a sandbox. The program writes a request into a shared folder, and gitro answers with the output of an allow-listed git command. The program never gets the repository, its credentials or any way to change it.

All tools

lsf bash
Lists every file under a folder as sorted relative paths, leaving out Unity's .meta files.
catcs bash
Prints the contents of every .cs file in a folder (not its subfolders), with UTF-8 byte order marks stripped.
toclip bash
Runs a command and copies its output to the clipboard.
csbundle bash
Bundles the .cs files of a source tree into one text file per folder, named by the folder's relative path.
csapply bash
Overwrites files in a project with same-named files from a flat folder, keeping their Unity .meta files, byte order marks and line endings.
gdm bash
Runs git diff showing only added and removed lines, with file headers but no context lines or hunk headers.
gitro bash
Runs read-only git commands from a fixed menu. gitro serve answers them through a shared folder, so a program without access to the repository, such as an AI agent in a sandbox, can still inspect it.
vs-tabs PowerShell
Saves and restores Visual Studio 2022 (17.9+) document tab layouts by name.

Install

jigs is a folder you clone, then load from your shell's startup file. In Git Bash:

git clone https://github.com/MangkorN/jigs /d/Repos/jigs
echo 'source /d/Repos/jigs/bash/bashrc' >> ~/.bashrc

New terminals pick the tools up. The README also covers the PowerShell scripts and Windows' execution policy.
