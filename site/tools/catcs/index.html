catcs

Prints the contents of every .cs file in a folder (not its subfolders), with UTF-8 byte order marks stripped.

Kind
Bash function
Script
bash/functions/catcs.sh
Page
docs/catcs.md
catcs [<dir>]   # every .cs file in <dir>, not its subdirectories, BOMs removed

catcsc does the same and copies the result to the clipboard.
